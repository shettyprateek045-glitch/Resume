## 💻 Flagship Projects & Repositories

1. **[AquaVision – Underwater Object Detection](https://github.com/shettyprateek045-glitch/AquaVision)**
   - *Problem*: Severe red light attenuation and particulate backscatter in aquatic environments hinder conventional vision models.
   - *Solution*: Curated underwater imagery, tuned anchor distributions, and trained custom YOLOv8 model architecture.
   - *Current Status*: YOLOv8 custom weights trained and pushed to GitHub; FP16 TensorRT edge deployment on Jetson Nano / Orin Nano planned.
   - *Live Demo*: Interactive playground available directly on the portfolio website.

2. **[KSP Sahayak – Karnataka State Police Copilot](https://github.com/shettyprateek045-glitch/Datathon.1)**
   - *Problem*: Bulky FIR retrieval and cross-lingual friction during high-pressure field situations.
   - *Solution*: Bilingual NLP assistant (English & Kannada), voice audio query synthesis, Role-Based Access Control (RBAC), and dynamic Leaflet GPS heatmap.
   - *Live URL*: [https://datathon-1-ofokflbj.onslate.in](https://datathon-1-ofokflbj.onslate.in)

3. **[IDP Multi-Domain Technology Orchestrator](https://github.com/shettyprateek045-glitch/MULTI-DOMAIN-TECH-FORGE)**
   - *Problem*: Disparate diagnostics and monitoring consoles across edge IoT, computer vision, and cloud microservices.
   - *Solution*: Next.js orchestration dashboard unifying real-time edge telemetry, automated code evaluation grading, and cloud API endpoints.
   - *Live URL*: [https://multi-domain-tech-fo-wkelilzm.onslate.in/](https://multi-domain-tech-fo-wkelilzm.onslate.in/)

4. **[RockyNish – Autonomous Edge Vision](https://github.com/shettyprateek045-glitch/ROCKYNISH)**
   - *Scope*: Real-time edge object detection pipeline targeting NVIDIA Jetson embedded environments.

5. **[Vidya-Sampadana – Open-Source Educational Tooling](https://github.com/shettyprateek045-glitch/Vidya-Sampadana)**
   - *Scope*: Collaborative academic resource platform and educational tooling.

6. **[ET-2.0 – ET AI Hackathon Solution](https://github.com/shettyprateek045-glitch/ET-2.0)**
   - *Scope*: Machine learning pipeline and predictive model submission for ET AI Hackathon 2.0.
