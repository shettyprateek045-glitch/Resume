# Prateek Shetty - Developer Portfolio

A responsive developer portfolio website showcasing expertise in Computer Science & Engineering (Data Science), Machine Learning, Computer Vision, and edge deployment on the NVIDIA Jetson Orin Nano.

## 🚀 Live Demo & Reference
Inspired by the modern dark aesthetic with neon green-to-cyan gradient accents.

## 📂 Tech Stack
- **HTML5 & CSS3** (Custom responsive layouts, CSS Grid/Flexbox, Glassmorphism, CSS Variables)
- **JavaScript (Vanilla)** (Interactive navigation, scroll spy, modal dialogs, IntersectionObserver animations)
- **Boxicons** (Vector icons)
- **Google Fonts** (Poppins)

## 📌 Features
- **Hero Section**: Profile presentation, introduction, social links, resume download.
- **About Me**: Academic background (RNSIT, CGPA 9.83), education timeline.
- **Skills**: Categorized into Languages, AI/ML & Computer Vision, Data Science & MLOps, Backend & Edge.
- **Experience**: YuvaIntern Computer Vision Specialist & Data Science Explorer internships.
- **Projects**: Real-Time Object Detection on Jetson Orin Nano, DataCentre AI, Maintenance Issue Reporting System, and live prototypes (KSP Sahayak, IDP Platform).
- **Achievements**: KSP Datathon, ISRO Bharatiya Antariksh Hackathon, Chaos & Clarity, Deloitte Job Simulation, QuizOff 2026.
- **Contact Form**: Interactive form with feedback modal and direct contact links.
