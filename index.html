AquaVision – Underwater Computer Vision & Marine Object Detection

An specialized underwater object detection system trained on custom-annotated marine imagery to accurately identify underwater marine life and submerged debris despite severe water turbidity and color distortion.

Problem Being Solved

Underwater optical environments suffer from severe wavelength-dependent light absorption (rapid attenuation of red light), particulate backscattering, and suspended sediment turbidity. Conventional pre-trained vision models degrade substantially in low-contrast, greenish-blue aquatic conditions, hindering autonomous marine exploration and aquatic conservation efforts.

My Exact Contribution
  • Curated, filtered, and formatted specialized underwater imagery datasets for supervised object detection.
  • Applied contrast enhancement and domain-specific data augmentation (color jittering, blur simulation, affine transformations) using Albumentations and OpenCV.
  • Configured and trained a custom YOLOv8 model architecture from scratch using PyTorch and Ultralytics.
  • Monitored training loss convergence, optimized anchor distributions, and benchmarked precision, recall, and mean Average Precision (mAP).
  • Packaged the validated model weights (.pt format) and inference scripts, publishing them to a structured GitHub repository.
Technologies Actually Used

Planned Features
